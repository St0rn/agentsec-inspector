# Référentiels

Référentiels reconnus par le modèle de données :

- OWASP Top 10 for LLM Applications, édition 2025. La V1 attribue `LLM01:2025` uniquement lorsque l’exécution observée d’un scénario justifie cette correspondance.
- OWASP Agentic AI Security / Agentic Application Security Initiative, pages de référence consultées pour la taxonomie des scénarios; aucune correspondance automatique stable n’est attribuée en l’absence d’identifiant versionné.
- MITRE ATLAS, contenu web consulté comme taxonomie; les références explicites de scénario sont conservées comme texte et non comme conclusion de vulnérabilité.
- MITRE ATT&CK Enterprise : reconnu dans le champ `frameworks`, mais aucune correspondance automatique n’est fournie en V1 faute de preuve d’une technique ATT&CK précise.

Date de gel documentaire : 2026-10-29. Une mise à jour du catalogue doit être revue manuellement afin d’éviter des correspondances artificielles.
